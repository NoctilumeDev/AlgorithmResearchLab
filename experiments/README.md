# 实验目录

当前状态：`RESEARCH_NOT_STARTED`。这里只有准备说明，没有实验实现、数据或运行结果。

用户明确启动研究以后，再选择首个最小问题和目录名。大数据、推荐、耦合与抽象是观察视角，目前不固定为代码包或版本目录。

后续每个实验按问题需要记录：

- 问题与探索/验证身份；
- 有限范围、前提和可否定的假设；
- 基线、单变量或组合矩阵；
- 算法允许读取的信息与独立评估路径；
- 数据或生成器、参数、环境及随机性；
- 指标、判据、测量精度与停止条件；
- 原始运行身份、失败及缺失证据；
- 支持、反驳或不可判断的结论及复现方式。

语义修改产生新计划版本；复跑产生新运行身份。实验命名不代表结果已成立。
