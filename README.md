# 漂移算法 · Drift Algorithm

AlgorithmResearchLab / 算法研究实验室

**指标持续改善时，它是否仍在帮助我们实现原来的目标？**

本研究关注：当目标与代理指标的定义保持不变时，代理指标对目标的决策有效性，如何随观测、优化和环境反馈发生变化，以及哪些变化能够识别、哪些无法判断。

以 Python 为实验语言，通过大数据算法与推荐算法两个可控实验面，逐步观察和检验这些问题。

## 核心问题

目标与代理指标的定义保持不变时，代理指标作为决策依据的有效性，可能怎样随观测、优化和环境反馈发生变化？哪些变化能够观察、解释或干预，哪些从现有信息无法判断？

重点关注一种静默情形：代理指标稳定或持续改善，常规指标未显示明显异常，但它对既定目标的决策有效性已经下降。是否出现、何时出现和如何判定，均需要实验或推导支持。

## 两个实验面与抽象提炼

- **大数据算法：** 观察采样、压缩、近似计算等方法的性质、误差与失效条件。
- **推荐算法：** 观察推荐、排序与选择规则的行为、目标取舍及反馈影响。
- **耦合与抽象：** 从单体、条件变化和组合实验中提炼目标、代理、观测、决策与反馈之间的机制及边界。

观察路径可以随证据调整。V1/V2/V3 记录取得的观察与解释能力，不预先固定算法清单、工期或必然发生的现象。

具体算法性质、反例、负结果、不可识别边界和有条件成立的机制，都可以成为成果。新算法是否必要，由研究证据决定。

## 待讨论研究候选：目标与证明路径变化

以下仅记录新问题线索，尚未纳入当前[研究范围](docs/research-scope.md)，也未证明与代理有效性漂移共享同一种机制。

以原始目标 A 及其证明义务 B 为例，候选问题包括：目标从 A 转向 A′、证明义务从 B 转向 B′，以及 B′ 已证明时，其对 B 或 A 的支持关系是否已经建立。

这些问题至少需要分别检查两个方面：

| 判断方面 | 待回答的问题 |
| --- | --- |
| 变更忠实性 | 目标或证明义务为什么改变？是否符合授权与允许的变更条件？ |
| 推导有效性 | 在声明条件下，B′ 是否足以推出 B 或 A？相应推导是否已经建立？ |

义务从 B 转向 B′ 的变化可以在 B 尚未被证明时发生。缺少推导支持不自动证明推导为假；推导成立也不自动授予义务变更权。

漂移、未经授权的替换、证明缺口和有效性下降可能相互重叠，暂不压成统一定义。其分类、判据及是否进入正式研究范围，均待后续讨论与证据支持。
